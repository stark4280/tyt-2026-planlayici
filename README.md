## ✨ Özellikler

### 🎯 Stratejik Program
- **90 günlük detaylı çalışma planı** - 3 evrede (TYT Temel, AYT Geçiş, AYT Zirve)
- **Pedagojik yaklaşım** - Önce TYT temelini sağlamlaştır, sonra AYT'ye geç
- **Önem oranları** - Her hafta ve konu için 0.00-1.00 arası önem derecesi
- **Günlük görevler** - Her gün için detaylı çalışma programı

### 📚 Kapsamlı Konu Takibi
- **280+ konu** - TYT ve AYT için tüm konular
- **10 ders** - Türkçe, Matematik, Fizik, Kimya, Biyoloji, Tarih, Coğrafya, Felsefe, Din Kültürü, Edebiyat
- **Önem rozetleri** - Kritik, Orta, Düşük önem seviyeleri
- **Soru sayısı bilgisi** - Her konu için beklenen soru sayısı

### 🔄 Bulut Senkronizasyonu
- **Firebase Realtime Database** - Cihazlar arası otomatik senkronizasyon
- **LocalStorage yedekleme** - İnternet olmadan da çalışır
- **Gerçek zamanlı güncelleme** - Değişiklikler anında kaydedilir

### 🎥 YouTube Entegrasyonu
- **Direkt konu anlatımı** - Her konu için YouTube arama linkleri
- **Hızlı erişim** - Tek tıkla konu anlatımı videolarına ulaş

### 📊 İlerleme Takibi
- **Genel ilerleme çubuğu** - Tamamlanan görevlerin yüzdesi
- **Görsel geri bildirim** - Tamamlanan konular işaretlenir
- **Geri sayım sayacı** - TYT sınavına kalan gün sayısı

### 🎨 Modern Tasarım
- **Glassmorphism** - Cam efekti ile modern arayüz
- **Gradient renkler** - Göz alıcı renk geçişleri
- **Smooth animasyonlar** - Akıcı geçişler ve hover efektleri
- **Responsive** - Mobil, tablet ve masaüstü uyumlu
- **Dark theme** - Göz yormayan koyu tema

## 📖 Kullanım

### İlk Kullanım

1. **Sayfayı Açın** - `index.html` dosyasını tarayıcıda açın
2. **Senkronizasyon** - Firebase otomatik bağlanacak (sağ üstte durum gösterilir)
3. **Programı İnceleyin** - 90 günlük programı gözden geçirin
4. **Çalışmaya Başlayın** - Günlük görevleri tamamlayın ve işaretleyin

### Günlük Kullanım

#### 1. Günlük Görevleri Tamamlama
- Haftalık program kartlarını açın
- Günün görevlerini okuyun
- Tamamladıkça checkbox'ları işaretleyin
- YouTube butonlarıyla konu anlatımlarına ulaşın

#### 2. Konu Takibi
- Konu listesi bölümüne gidin
- Bitirdiğiniz konuları işaretleyin
- Önem derecelerine göre öncelik verin
- Kritik konulara odaklanın

#### 3. İlerleme Kontrolü
- Üst menüdeki ilerleme çubuğunu kontrol edin
- Genel tamamlanma yüzdenizi görün
- Eksik konuları belirleyin

### Altın Kurallar

💡 **Her gün sabah ilk işin:**
- 20 paragraf çöz
- 15 problem çöz

🎯 **Haftalık rutin:**
- Pazartesi-Cuma: Günlük program
- Cumartesi: Deneme sınavı
- Pazar: Haftalık tekrar

🔥 **Kritik dönemler:**
- Gün 15-25: Problem haftası (0.98 önem)
- Gün 64-77: Limit-Türev dönemi (1.00 önem)
- Gün 78-84: İntegral haftası (0.98 önem)

## 📅 90 Günlük Program

### 🟢 1. EVRE: TYT Temel Atma (Gün 1-35)
**Hedef:** TYT konularını bitir, AYT'ye zemin hazırla

- **Hafta 1-2:** Temel kavramlar, sayı basamakları, paragraf
- **Hafta 3-4:** Problemler (Altın Dönem) - 0.98 önem
- **Hafta 5:** TYT son konular, fonksiyonlar (AYT kapısı)

**Önem Oranı:** 0.85-0.98

### 🟣 2. EVRE: AYT Geçiş (Gün 36-63)
**Hedef:** AYT'ye başla, TYT'yi canlı tut

- **Hafta 6-7:** Polinomlar, analitik geometri, trigonometri
- **Hafta 8-9:** Logaritma, diziler, fonksiyon uygulamaları
- **TYT Takviyesi:** Haftada 2 genel deneme + günlük 15 problem + 15 paragraf

**Önem Oranı:** 0.92-0.95

### 🔴 3. EVRE: AYT Zirve (Gün 64-90)
**Hedef:** Limit, Türev, İntegral + yoğun denemeler

- **Hafta 10-11:** Limit ve Türev (her gün 4 saat) - 1.00 önem
- **Hafta 12:** İntegral (her gün 4 saat) - 0.98 önem
- **Hafta 13:** Son rötuşlar, MEB çıkmış sorular, sınav provası

**Önem Oranı:** 0.95-1.00

## 🔥 Firebase Yapılandırması

### Mevcut Yapılandırma
Proje zaten yapılandırılmış bir Firebase projesi kullanıyor. Kendi projenizi kullanmak isterseniz:

### Yeni Firebase Projesi Oluşturma

1. **Firebase Console'a Git**
   - https://console.firebase.google.com/
   - Google hesabınızla giriş yapın

2. **Yeni Proje Oluştur**
   - "Add project" butonuna tıklayın
   - Proje adı: `tyt-2026-planlayici`
   - Google Analytics: İsteğe bağlı

3. **Realtime Database Ekle**
   - Sol menüden "Realtime Database" seçin
   - "Create Database" butonuna tıklayın
   - Konum: `europe-west1` (Avrupa)
   - Güvenlik kuralları: Test modunda başlat

4. **Web Uygulaması Ekle**
   - Proje ayarlarından "Add app" → Web
   - App nickname: `TYT Planlayıcı`
   - Firebase Hosting: Hayır (şimdilik)

5. **Yapılandırma Kodunu Kopyala**
```javascript
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "YOUR_PROJECT.firebaseapp.com",
    databaseURL: "https://YOUR_PROJECT.firebasedatabase.app",
    projectId: "YOUR_PROJECT",
    storageBucket: "YOUR_PROJECT.appspot.com",
    messagingSenderId: "YOUR_SENDER_ID",
    appId: "YOUR_APP_ID"
};
```

6. **index.html'de Değiştir**
   - `index.html` dosyasını açın
   - `firebaseConfig` nesnesini bulun (satır ~360)
   - Kendi yapılandırmanızla değiştirin

### Güvenlik Kuralları (Önerilen)

```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

**Not:** Production için daha güvenli kurallar kullanın (Authentication ekleyin).
